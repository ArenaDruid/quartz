# 序

五一打算推一款很老的Galgame ——《黎明前的琉璃色》，然后发现这部galgame在窗口化模式下在2k显示器下显得太小了，而我又不想开全屏模式（况且直接全屏能够明显感到分辨率不足的马赛克）。而我以前使用过Lossless Scaling给《Minecraft》进行超分和插帧（关于这部分的内容可以见著名minecraft区UP主籽岷的视频：[玩MC帧数不够？小黄鸭（AI插帧）来补！LSFG 3.0](https://www.bilibili.com/video/BV1gBcVeEEsh) ）。然而在Lossless Scaling遇到了相当多的问题，不想开全屏模式的核心诉求也没有完全解决，最后一番周折使用了Mapgie的开发中的“窗口模式缩放”功能，实现了给Galgame窗口模式提高分辨率的功能。

# 第一次尝试：全屏模式缩放
## 失败的尝试：Lossless Scaling

我先简要说一说在使用Lossless Scaling给《黎明前的琉璃色》超分遇到的核心问题其实就是：**卡顿**。这种卡顿并不是电脑硬件性能的问题，我在测试中观测过CPU、GPU和内存的负载，均没有明显的过载和大幅的占用上升现象。我也尝试过切换各种各样的配置，包括但不限于算法、画面捕获方式、各种兼容性和性能选项，但均无法缓解这个问题。而其背后的原因也我个人能力不足也无法查明，因而只能选择放弃这个方案。

## Mapgie 的简单使用

### Mapgie 的介绍

我感觉在互联网应当会有与Lossless Scaling提供相似功能的软件，在互联网上冲了一会浪之后，我找到了本文的主角：[Blinue/Magpie: An all-purpose window upscaler for Windows 10/11.](https://github.com/Blinue/Magpie)。根据其在[Github的介绍](https://github.com/Blinue/Magpie/blob/dev/README_ZH.md)，Magpie 是一个轻量级的窗口缩放工具，内置了多种高效的缩放算法和滤镜。它主要用于提升游戏画质和让不支持全屏化的游戏也能全屏显示等。

其特色功能包括：

- 将任何窗口放大至全屏
- 众多内置算法，包括 Lanczos、[Anime4K](https://github.com/bloc97/Anime4K)、[FSR](https://github.com/GPUOpen-Effects/FidelityFX-FSR)、Adaptive Sharpen、多种 CRT 着色器等
- 基于 WinUI 的用户界面，支持浅色和深色主题
- 为特定窗口创建配置文件
- 多屏幕支持

### Mapgie 的下载与简单使用

Mapgie正式版的下载途径比较多样，目前已知的方案有：**在[Releases · Blinue/Magpie](https://github.com/Blinue/Magpie/releases)手动下载**
以及在[View Magpie on UniGetUI](https://marticliment.com/unigetui/share/?name=Magpie&id=magpie&sourceName=extras&managerName=Scoop)自动下载（自动下载方案请自行学习有关 Scoop 或者 UnigetUI 的相关知识）。

在下载好并打开Mapgie之后，先单击游戏页面使之进入前台，然后直接输入“Windows+Shift+A”键位即可将窗口化的软件以超分算法全屏缩放。

# Mapgie的窗口模式缩放

>[!warning] 警告
>Mapgie的窗口模式缩放在本文撰写期间仍属于开发中功能，请使用者在了解并愿意承担使用开发中功能可能带来的风险再下载并使用其功能，在使用中遇到任何BUG、或者有任何意见和建议，请以积极、友善的态度与开发者进行沟通。

尽管 Mapgie 提供了超分算法，但是在缩放后依旧会将窗口变为全屏，这并没有完成我最初想要实现了**放大窗口**的需求，而后我在 Mapgie 的 issue 栏目中看到了有网友已经向开发者提出了类似的功能请求：[窗口化缩放 Windowed Mode · Issue #135 · Blinue/Magpie](https://github.com/Blinue/Magpie/issues/135)。而开发者在最新的动态中表示正在将这个功能作为开发中，并且已经做出了若干开发中版本（关于这个功能的开发状态可以参见[[WIP]窗口化缩放 by Blinue · Pull Request #1071 · Blinue/Magpie](https://github.com/Blinue/Magpie/pull/1071)）。因此我们可以在项目中找到最新的开发中版本下载（下载地址在[Github Action](https://github.com/Blinue/Magpie/actions?query=branch%3Awindowed-mode)可以找到）

![[Pasted image 20250503165506.png]]
*在 Github Action 中将分支设为 "windowed-mode" 能够精确找出拥有窗口模式缩放功能的软件开发中版本*

在下载并打开有窗口模式缩放功能开发版的Mapgie后，先单击游戏页面使之进入前台，然后根据**主页-快捷键-窗口模式缩放**的设置输入快捷键即可将窗口化的软件以超分算法以窗口形式缩放。

# 结语
## 关于 Mapgie

首先需要感谢 Mapgie 背后的开发团队开发出这款软件，使得许多旧时代的游戏能够以相对更好的画质出现在我们这种想要体验经典游戏的玩家的面前。本文仅仅介绍了 Mapgie 最简单的用法，Mapgie 还有不同的缩放算法、画面捕捉方法、以及各种性能和高级配置可供使用者进行配置。请读者自行前往 Mapgie 的Github 官网了解。除此之外，本人认为这个窗口化缩放的功能是一个相当有前景的功能，希望这个功能能够早日并入正式版之中。
## 本文作者的絮絮叨叨

《黎明前的琉璃色》可以说是我早年间仍处于galgame探索阶段的体验过的作品，虽说那时的我那时并没有体验太多内容，甚至可以说那时看过什么剧情都记忆模糊了。八月社一直是我比较钟意的一个社团，《黎明前的琉璃色》各位女主的衣品和画风也是我直到现在都相当钟意的。因而本文以这部作品为引子和示例，希望能够给读者带来一点帮助和启发，也希望读者如果有任何意见和建议能够积极友善地和我交流。
